# KDE Classic Cursors for Windows

![Preview](preview.png)

KDE Classic cursor theme for Windows — a faithful port of the classic KDE cursors from KDE 3.x and earlier, remastered.

These cursors bring back the nostalgic look and feel of early KDE desktop environments, now usable on Windows 10/11.

## Preview

![Preview](preview.png)

## Installation

1. **Right-click** `INSTALL.inf` and select **"Install"**.
2. Open **Control Panel** → **Mouse** → **Pointers**.
3. Select **"KDE Classic"** from the Scheme dropdown.
4. Click **Apply** and enjoy!

Or manually copy all `.cur` files to `%SystemRoot%\Cursors\KDE-Classic\` and apply the scheme via Mouse settings.
